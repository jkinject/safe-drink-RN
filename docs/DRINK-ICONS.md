# 술 아이콘 에셋

`assets/images/drink/` 의 12종 PNG. 프리셋 카드·기록 타일·아이콘 선택기에서 쓴다.
표시는 `src/components/drink-icon.tsx` 의 `DrinkIcon` 하나로만 한다.

## 왜 이모지가 아닌가

이모지는 플랫폼(삼성/픽셀/iOS)마다 그림과 색이 달라 디자인을 통제할 수 없고,
소주잔·양주잔이 같은 🥃 로 뭉쳐 종류를 구분하지 못한다.

## 스타일 규칙

새 아이콘을 추가할 때도 아래를 지켜야 세트가 흐트러지지 않는다.

- 굵기가 일정한 **네이비(#2D2B52) 외곽선**
- **플랫한 원색 채움** + 하이라이트 1개, 그라디언트·그림자·반사 없음
- 정사각 캔버스, 오브젝트가 약 80% 차지, 배경 투명
- 텍스트·라벨 문구 없음

## 재생성 방법

Replicate 토큰은 `~/.replicate_api_token`.

1. **생성** — `openai/gpt-image-2`
   - 이 모델은 **투명 배경을 지원하지 않는다**. 앱 배경색(#EEEDF8) 단색으로 생성한다.
   - 12종 프롬프트는 공통 STYLE 문장 + 술별 subject 조합. 세트 일관성은 이 공통 문장이 만든다.
2. **배경 제거** — `851-labs/background-remover` (`background_type: rgba`)
   - 결과를 여백 기준으로 크롭 → 정사각 캔버스 중앙 배치 → 256px 로 축소.
   - 크롭·중앙 정렬을 해야 아이콘마다 실제 크기가 들쭉날쭉하지 않다.

스크립트 원본은 작업 당시 스크래치패드에 있었다(`gen_icons.py`, `cut_bg.py`).
다시 만들 때는 위 두 단계와 스타일 규칙만 지키면 된다.

## 데이터 호환

`DrinkPreset.icon` 이 아이콘 키다. 아이콘 도입 전 저장된 프리셋은 `emoji` 만 갖고 있어서

- 기본 프리셋은 라벨로 원본을 찾아 `icon` 을 채우고 (`presetStorage.withDefaultIcons`)
- 커스텀 프리셋은 `resolveDrinkIcon` 이 이모지를 대응표로 매핑한다.

`emoji` 필드는 이 호환 목적으로만 남아 있다. 새로 저장하는 프리셋에는 쓰지 않는다.
